# ClassHub Flutter starter

Implements the agreed design direction: Dark Premium by default, purple/blue accents, rounded cards, home/class chat/private messages/files/polls/settings, responsive navigation, light/dark switch, Mood toggle, calm readable chat and compact density toggle.

**Important:** this is a front-end prototype. Chat and votes are demo data in memory. Real login, shared messaging, cloud sync, file upload and notifications still require Firebase/Supabase and configuration.

## Build
1. Install Flutter SDK.
2. Open this folder in a terminal.
3. Run `flutter create .` to generate platform folders.
4. Run `flutter pub get`.
5. Run `flutter run`.
6. To build APK: `flutter build apk --release`.
